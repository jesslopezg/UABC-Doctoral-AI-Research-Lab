# UABC Doctoral AI Research Lab

Laboratorio doctoral práctico de 120 minutos.

## Instalación

```bash
npm install
npm run dev
```

## Vercel

Importar repositorio y seleccionar Vite. Build: `npm run build`, output: `dist`.

Cinco módulos, cronómetro, notas con guardado local, CSV local, correlación exploratoria, gráficos y PDF. Datos iniciales sintéticos. No incluye integración con IA ni escudo oficial.
